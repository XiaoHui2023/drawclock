# 验证流程

## 分层门

1. 静态结构门检查禁用元素、命名空间、外部引用、组件与图形基数。
2. 坐标门检查每个边端点和可见引脚端点的同一屏幕坐标。
3. 浏览器运行门确认原生嵌套 SVG 的 CTM 关系。
4. librsvg 把当前 SVG 扁平化为另一份 SVG；独立检查器确认实际绘制路径足以覆盖背景、边和全部组件。
5. 发行门对解压后的冻结程序与 `python -I -S src` 分别生成并渲染，绑定真实包内容。

## 故障样本

- 把组件换成 XHTML `foreignObject`；
- 保留合法源文件，但用只含背景与边的扁平化结果替换渲染证据；
- 删除一个组件图形，保留组件组；
- 加入外部图片 URL 或事件属性。

成功基线通过且上述负例全部被拒绝，才能声明覆盖当前静态查看器兼容范围。
