# 兼容合同

## 必须满足

- 根元素位于 SVG 命名空间，`viewBox`、`width` 和 `height` 有效；
- 器件与文字由原生 SVG 元素表达；
- 文件自包含，打开本地文件不需要 HTTP 服务、浏览器、网络或同目录附件；
- XML 可解析，坐标与样式使用查看器共同支持的静态子集。

## 拒绝内容

- `foreignObject` 与 XHTML；
- `script`、事件属性及交互；
- `iframe`、`canvas`、音视频；
- HTTP、文件系统或上级目录资源引用；
- 解析失败后仍继续生成的空占位。

当器件库标签无法转换为共同子集时，绘图应失败并指出不兼容结构。降级为缺图或只剩连线不属于兼容结果。
