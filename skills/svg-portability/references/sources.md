# 来源

- [W3C SVG 2 Embedded Content](https://www.w3.org/TR/SVG/embedded.html)：`foreignObject` 是外部内容扩展点，用户代理不必提供任意外部内容处理器。
- [librsvg Supported SVG and CSS features](https://gnome.pages.gitlab.gnome.org/librsvg/devel-docs/features.html)：列出 librsvg 支持的静态元素、属性与 CSS 子集。
- [librsvg product](https://gnome.pages.gitlab.gnome.org/librsvg/devel-docs/product.html)：说明 GNOME 平台库、`rsvg-convert` 与缩略图集成。
- [librsvg text layout](https://gnome.pages.gitlab.gnome.org/librsvg/devel-docs/text_layout.html)：说明原生 `text`、`tspan`、锚点与字体属性的支持边界。
- [Noto CJK](https://github.com/notofonts/noto-cjk)：简体中文字形来源；Noto Sans CJK 使用 SIL Open Font License 1.1。项目仅嵌入固定标题的四个轮廓，许可文本在 `licenses/NotoSansCJK-OFL-1.1.txt`。

资料于 2026-09-01 访问。项目实现只依赖 Python 标准库；上述页面是设计与兼容性依据，不是运行时依赖。
