# 原生 SVG 组合

## 单一坐标系

- 根 `viewBox` 覆盖器件图形、文字、边、junction、跨线圆弧和外边距。
- 器件图形使用嵌套原生 `svg` 或 `g`，位置直接来自节点坐标。
- 边端点直接使用端口绝对坐标，不经过 CSS 盒模型或周界投影。
- 图层顺序为背景、边、junction、器件和文字，确保器件轮廓覆盖边的接触末端。

## 静态成品

允许基础图元、路径、分组、静态样式和原生 `text`。资源必须内嵌；片段引用只能指向同一文件中的 ID。禁止脚本、事件属性、外部 URL 和 HTML `foreignObject`。

文字使用明确的 `x`、`y`、字号、字体族与 `text-anchor`。字体族提供常见回退，布局障碍范围按预计文字宽度计算；不得依赖 HTML 行盒再次决定位置。

对固定且必须跨系统显示的 CJK 标题，字体回退不是自包含保证：最小 Linux 环境可能完全没有 CJK 字体。可从 OFL 开放字体在开发阶段提取所需字形轮廓，最终只输出原生 `path`、可访问标签和许可文本。字体本体与提取工具不应成为运行时依赖。
