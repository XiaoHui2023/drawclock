# 器件标签转换

器件库可以继续使用 draw.io 的固定 HTML 标签，但最终 SVG 需要把可确定的结构转换为原生 SVG。转换依据标签树、CSS 长度和父子坐标，不依据 `kind`、title 或实例名。

## 当前可转换结构

- 固定尺寸的 `div` 容器；
- `left`、`top`、`width`、`height` 的 px 或百分比长度；
- 内嵌原生 `svg` 与基础图元；
- 绝对定位的 `span` 或无子节点 `div` 文字；
- 文字的 `translateX(-50%)` 和 `translate(-50%,-50%)` 居中语义。

不支持的 HTML 元素、容器变换、脚本事件或外部资源应立即报错。静默忽略会生成“线存在、器件消失”的无效成品。

新增结构时先增加最小成功例和不兼容负例，再扩展通用转换规则。不得为单个器件或示例坐标增加分支。
