# 视觉质量门

## 硬门

- 每个逻辑节点恰有一个可见器件图形和实例文字；
- 每条逻辑边恰有一条可追踪路线，起止点与可见引脚端点重合；
- 无器件、文字、路线或跨线符号裁切；
- 无斜线、断线、外部资源和查看器专属空白节点。
- 末端频率标题、值、最下行和动态长值均在 `viewBox` 内；三列的 x 不因缺省值变动。

## 多渲染器验收

浏览器检查 DOM CTM 与端口接触几何；librsvg 检查 GNOME 静态查看链是否实际绘制每个器件。两者职责不同，不能互相替代。

兼容性检查至少保存一个浏览器正常、静态查看器丢失器件的历史负例。检查器须拒绝该负例，并接受同拓扑的原生 SVG 成功例。
