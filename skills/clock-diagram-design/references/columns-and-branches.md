# 阅读方向、列与支路

- 全图从左向右阅读，单个支路像一行条目横向延伸。
- 多条相似支路纵向排列，相同阶段尽量共列；例如用户给所有 mux 相同 `layout_column` 时，应尽量形成一条整齐竖列。
- 某支路多一个或少一个器件时，优先保持主要阶段对齐，不让后续列参差扩散。
- 简单相邻节点的端口若能水平直连，应放在同一 y；避免为了紧凑产生一次无意义上下折线。
- 汇聚节点的输入顺序和支路上下顺序应协同，避免两条本来平行的末端路线交换后再交叉。
- 输入源通常居左、输出时钟通常居右，但这是阅读惯例，不是绝对边界。服务中部的小范围源可放在中间偏左；贯穿全图且连接最上方支路的源通常放在上方更自然。

`layout_column` 是主观列权重：数字越小越左，越大越右；未填写时完全由连接关系决定。它不指定像素，也不强迫冲突边反向。
