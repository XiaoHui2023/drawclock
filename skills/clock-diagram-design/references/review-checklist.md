# 设计验收清单

## 先看硬错误

- 节点、边、端口数量与 JSON 一致；
- 每条边起止端口正确，无偏移、斜线、断线；
- 无节点/标签穿越、节点重叠、异网重叠；
- 无裁切，最上、最下、最左、最右可见元素都有外边距。

## 再看结构质量

- 相似支路是否成行，指定等级是否成列；
- 同源多路连接是否只有必要干线；
- 远距消费者是否值得分簇或复制源显示；
- mux 输入支路是否因不合理上下顺序交叉；
- 是否存在绕到底部再返回、外凸、回头或局部小折线；
- 能直连的边是否直连；单边最大折点是否合理；
- 交叉是否确实不可避免，跨线与 junction 是否不混淆；
- 在不降低上述质量时，空白能否进一步压缩。

## 验证方式

同一检查同时落到：最小反例、复杂手工例、属性扰动语料和大规模压力例。改算法后比较质量向量，不只判断“能生成 SVG”。质量检测属于开发与 Agent 工艺，不增加公开 CLI 参数或子功能。
