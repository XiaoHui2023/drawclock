# 标签、留白与画布

## 可见占用范围

器件的视觉障碍范围是本体、引脚、实例名、端口文字和外置标签的并集。边穿过器件下方文字，等同于穿过器件。仅检测 mxGeometry 选择框是不够的。

## 紧凑度

满足不碰撞和路由净空后压缩节点间隙。紧凑指标使用“画布面积减去器件与标签可见面积”后的空白，而不是单纯宽高。压缩时保持：

- 标签不重叠；
- 线路有可辨认间距；
- 简单链水平对齐；
- 干线和支线有稳定通道；
- 不新增交叉或折点。

## SVG 边界

viewBox 必须覆盖：所有器件、溢出标签、完整线段、junction dot、跨线圆弧和必要外边距。最底部出现线却没有目标，通常是可见范围或边界计算遗漏，必须作为失败处理。

输出内容固定为 SVG；后缀不改变格式。成品不承担后续 draw.io 编辑能力。
