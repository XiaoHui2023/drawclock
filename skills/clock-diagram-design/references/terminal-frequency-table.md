# 末端行与频率注释

## 结构

- 零出度节点是末端，不依赖器件 title；
- 所有末端在最右列对齐，每个末端独占一行；
- 注释表无边框、无底色，位于末端右侧；
- `frequencies`数组从左到右定义任意数量列，整表列数取最长末端数组；较短行缺项为空；
- 表头由全局选项提供，数量与列数一致；没有自定义表头时显示“频率 1”等，文字黑色；
- 标题和值都支持显式换行，默认居中，可全局选择左/右对齐；宽度以最长显式行计算，多行内容需要预留行高；
- 全部数组为空时不生成表组；数组存在的空值列仍保留标题。旧固定字段仅在兼容模式按原非空列规则显示；
- 数值与对应末端的入口轴对齐，文字红色；未填字段不输出占位字符。

## 计算要求

列中心和列宽必须一次性由全部标题/值计算，不得在生成后人工移动。表头、长值和最后一行都必须进入 `viewBox` 可见边界。

## 门禁

- 末端 x 座标唯一，行轴 y 座标两两不同；
- 每个标题只出现一次，顺序和数组下标映射一致，不按内容隐藏数组中的列；
- 每个非空值同时携带逻辑末端 id 和频率字段，便于独立 Oracle 追溯；
- 交换数组下标、遗漏元素列、保留无数组列的空表、使用黑色值、让两个末端共行或裁切长值都必须失败；兼容模式仍检查旧固定字段的条件列。
