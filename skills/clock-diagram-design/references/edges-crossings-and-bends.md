# 连线、交叉与折点

## 基本形态

- 每条线恰好连接一个源端口和一个目标端口。
- 线段只水平或垂直；端点不得偏离可见端口。
- 从器件输出水平离开本体一小段后转向；进入输入也保留水平接近段。
- 线不能穿过自己的器件、其他器件或文字。

## 折点最少

直线可达时用 0 折点；L 形可达时不使用 H-V-H；相同质量下选择更短路径。以下都视为异常：

- `gate_b→mux` 无障碍却向外凸一次并穿过 `div_a→mux`；
- 本可“下、右”却变为“下、右、下、右”；
- 两个端口基本共线，仅因节点 y 微偏产生小折线；
- 为缩小画布而给清晰路径增加折点。

“无交叉但有折点”应进入 Agent 反事实检查，但不能直接判错。对实际只服务一边的零入度显示设施，
尝试移动完整器件使输出端口与目标端口同轴并重接直线；只有器件/文字不碰撞、其它线不穿过新位置、
异网重叠和交叉不增加、线长不增加时，才把原折点登记为可避免。必要绕障碍的折线必须保留。

“整根线有交叉”也不能直接放过全部折点。沿路线弧长排序交叉点、junction 和端口邻域，将路线分为
whole、prefix、interior、suffix 区段；分别统计区段长度与内部折点。最后交叉点后的 suffix 若没有
新的交叉，却能通过通用下游拓扑/视觉行移动清零折点，并且不新增器件/文字穿越、异网重叠、交叉、
端点引线错误或线长，则原折点是异常。移动目标造成的既有支路线冲突必须扩展成视觉行所有权闭包，
不能只移一个器件；真实障碍、入边端口偏移不一致则应拒绝候选。

## 交叉

先通过行序、列对齐、源位置和路由消除可避免交叉。剩余交叉才应用跨线风格：默认圆弧，也可用 gap、sharp 或 none。junction dot 只表示同网真实连接，跨线圆弧不表示连接。

质量检查要区分交叉总数和不同交叉点；多条线在一个拥挤点交叉通常比统计数字看起来更糟。
