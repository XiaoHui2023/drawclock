# 参考资料

- [draw.io 自定义形状库文件格式](https://www.drawio.com/docs/reference/format-custom-shape-library/)：mxlibrary 外层、条目必需字段和 data/xml 形式。
- [draw.io 自定义形状](https://www.drawio.com/docs/tutorials/custom-shapes/)：形状几何、连接点和样式的官方入口。
- [draw.io 自定义库使用方式](https://www.drawio.com/docs/manual/advanced/custom-shape-libraries/)：独立库文件、共享和加载行为。

采用原则：官方格式定义决定文件规则；项目自身的几何生成器和端口解析器决定更严格的 drawclock 不变量。
