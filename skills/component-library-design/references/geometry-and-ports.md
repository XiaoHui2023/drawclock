# 几何、标签与端口

## 单一几何来源

定义器件的可见本体、引脚端点和标签区域，并由它们导出：

1. 选择框宽高；
2. mxGeometry；
3. SVG 或 HTML 标签中的坐标；
4. style 的 `points=[[x,y,0,0,0], ...]`；
5. 预览图与端口对齐测试期望值。

不要分别手调这些数字。端口绝对坐标应满足：

`P = (node_x + x_rel * width, node_y + y_rel * height)`。

测试必须把这个点与可见引脚末端的解析几何比较，而不是与外框边缘比较。

## 端口约定

- `x < 0.5` 归为输入，`x >= 0.5` 归为输出。
- 同侧端口按纵坐标从上到下稳定排序。
- 单输入内部名为 `left`；多输入为 `in0..inN`。
- 单输出内部名按端口结构为 `right` 或 `out`；多输出为 `out0..outN`。
- 用户连接键优先取端口旁的可见标签；不能一一对应时退回稳定数字键。
- 未连接的输入端口合法，因此 mux2 可以只提供 `0` 或只提供 `1`。

连接点 style 应关闭周界再投影：生成边时使用精确的 `exitX/exitY`、`entryX/entryY` 和 `exitPerimeter=0/entryPerimeter=0`。

## 标签与可见占用

固定器件建议使用不可缩放选择框，并允许 HTML 标签溢出显示。标签虽不改变本体尺寸，却是路由障碍物：长实例名、端口文字和外置说明都要并入 visible footprint。

标签模板需要占位符时，库对象和 style 均保留 placeholder 能力；生成最终 SVG 前应烘焙实际值，使输出不依赖编辑器再次解释模板。
