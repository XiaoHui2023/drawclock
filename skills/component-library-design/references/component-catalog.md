# 当前器件目录

本页是项目自带 `drawio-lib/drawclock.xml` 的导航，不是布局器的白名单。外部库可以增加任意 title，只要满足通用合约。

## 从源头到末端

| 类别 | title | 端口概况 | 使用提示 |
| --- | --- | --- | --- |
| 源头 | `source`, `from`, `pad` | 无输入、单输出 | 表示内部源、外部引用或 pad；布局只按零入度判断源头 |
| 时钟生成 | `pll`, `pll2` | 单输入；`pll2` 双输出 | 双输出引用使用显式输出键 |
| 选择 | `mux2`～`mux6` | 2～6 输入、单输出 | 只连接实际使用的输入即可 |
| 变换 | `div`, `div_r`, `dto`, `inv` | 单输入、单输出 | `div_r` 等显示属性属于器件元数据 |
| 门控/单元 | `gate`, `cell`, `inv_cell`, `inv_mux`, `gen_cell`, `occ_clk_cell`, `bist_clk_cell` | 通常单入单出 | 复用家族几何和标签规范 |
| 组合单元 | `occ_bist_clk_cell` | 单输入、无输出 | 以库中真实端口为准，不按名称猜测 |
| 末端 | `clock` | 单输入、无输出 | 常作为时钟树叶节点 |

## 设计新器件

优先选择最接近的视觉家族并复用共享构造器。只有轮廓或端口结构真正不同才新建几何模块。命名要表达器件类型，不包含项目实例、芯片代号或人员信息。

新器件至少提供：稳定 title、默认尺寸、可见本体、明确端口、标签模板、预览 SVG 和几何验证。布局器不应因新增器件而修改。
