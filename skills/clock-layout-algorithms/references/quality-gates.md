# 质量目标与门禁

## 硬门

- 每个配置节点至少有一个对应渲染节点；只有零入度源允许显示副本。
- 每个 source 引用恰好生成一条逻辑边，且连接到正确的源/目标端口。
- 端点与可见引脚绝对坐标一致；所有线段正交。
- 节点本体不重叠；边不穿器件、标签或自身器件；异网线段不重合。
- 所有有向边整体从较小 rank 指向较大 rank；SVG 边界覆盖节点、标签、线和跨线符号。

## 优化指标

按顺序比较候选：

1. 交叉总数、不同交叉点数、每条边的交叉点/交叉对事件、每个逻辑源所有出边的交叉归因；
2. 总折点、单边最大折点、可消除折点；
3. 曼哈顿总长度、异常绕行比、最长竖向贯穿；
4. 同列偏好满足率、简单链直线率、支路列方差；
5. 去除器件和标签后的空白面积、总面积；
6. 运行时间和峰值内存。

每条边还要报告端点纵向跨度（像素与典型行距单位）和两端之间的实际视觉行数；每个逻辑源报告出边数、交叉点并集、交叉对事件总数、最大纵向行距和最大夹行数。独立 Oracle 必须从最终可见几何复算这些值并与生产报告逐项相等。共享同一源端口的重合干线属于同网 junction，不计为交叉。

大图统计不得为了列举所有相交边而物化扇出边的笛卡尔积。用区间/扫描线找到交叉几何后，对参与边累计交叉点集合和交叉对事件计数，空间保持与边数、真实交叉事件近似线性。

面积和耗时不能覆盖前面的视觉质量退化。

## 反例族

- 单链、树分支、双源 mux 汇聚；
- 长短不对称输入：`root→gate→div→mux` 与 `root→gate→mux`；
- 一分二末端紧邻单末端，防止末端交换后交叉；
- 同一源跨近簇与远簇，检查一条干线或源副本选择；
- 三个典型行距以内保持单源，刚超过三行即形成候选；另用约四行的中距离样本证明优化不依赖“超远”空带；
- 注入一处异网正交交叉，要求两条边及两个逻辑源均准确归因一次；同网共享干线不得误报；
- 长标签、端口上下错位、多输出、缺省 mux 输入；
- 多列相似支路及 `layout_column` 共列；
- 随机重命名、交换输入顺序、扰动器件尺寸和端口，防止按测试名称打补丁；
- 512～4096 终端规模，检查质量不变量与增长趋势。
