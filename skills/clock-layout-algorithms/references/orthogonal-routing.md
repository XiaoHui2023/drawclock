# 正交路由与总线

## 精确端口到端口

路由起点和终点直接由器件几何计算。沿端口朝向保留最短水平 stub 后进入公共通道；终点同理。起点、终点和所有 waypoint 都必须形成水平或垂直线段。

路由障碍物是器件本体、外置标签和必要净空的并集。禁止生成图后目测校准端点。

## 候选路径

使用正交可见图或等价的有限通道图：顶点来自端口、障碍物边界和可用通道；以折点数、长度和拥塞为代价寻路。若两端口 y 相同且无遮挡，零折点直连必须成为最优候选。

可见通道必须包含终态每个器件本体、名称、原生标签与 description 注释联合外框的上/下边界，
再按路由净空向外扩张。不能只复用已有 route y 或整图最上/最下轨道：已有路线可能正是错误结果，
会把第一个合法的内部边界通道排除在搜索空间之外。进入完整整图评分前可用外框相交测试删除不可行
lane，但不得按局部评分截成固定 top-N。

单一“首选净空”扩张仍可能漏解：密集图中的合法低交叉通道可能位于可见障碍外框与首选净空边界之间。
有限可见图至少同时纳入首选净空边界和由线宽、跨线桥、网格尺度导出的最小安全间距边界；二者之间
若存在路线/障碍事件点，还应按事件分区取代表通道。最小安全间距只负责生成候选，不能绕过最终的
器件/文字碰撞、端点净空、异网重叠、同网无环和全图质量事务。

通道搜索是有限但不固定 top-N 的渐进深化。先用廉价局部量对同一方向候选排序，再逐个提交到
整图终态硬门；只有采用一个候选或穷尽该方向才停止。固定保留前三/五条会在合法 lane 排名更后时
形成 coverage escape。器件图形、名称、原生标签和 description 注释共同构成障碍 envelope。

简化路径时反复执行：

1. 删除重复点；
2. 删除共线中间点；
3. 尝试用单个 L 形或直线替换子路径；
4. 只有替换后仍不穿障碍、不增加异网重合或交叉才接受。

这能结构性消除 H-V-H 外凸和“下、右、下、右”的多余折线。

## 同源总线与 junction

只有来自同一逻辑源端口的边可以共享线段。源端口连接多个目标时构造一棵 rectilinear arborescence：一条竖向 trunk 穿过相邻消费者行，每个目标用短横向支线接入，并在真实分叉点画 junction dot。

当某个后排目标位于密集分支带之外，优先让其沿既有纵干线到目标外侧可见通道后再横出，而不是
提前横穿若干行再在远端纵降。允许增加最多两个折点的候选只有在至少减少两个不同交叉点和三个
交叉事件、且所有硬门不退化时才胜出；另保留无需增加折点即可延迟出口的等价形态。

不同网络即使几何接近也不能重合。一个源不应无故生成两条覆盖同一消费簇的平行竖干线。

## 远距源副本

当零入度源服务多个分离消费簇时，可以仅在渲染层复制源符号。把排序后的精确目标端口轴视为一维设施问题：每个连续分区的共享竖干线跨度只计算一次，每新增一个设施则支付当前器件图形与标签真实可视框的周长成本。只有切开某个间隙节省的同网线段并集长度严格超过设施成本且完整质量门不退化时才复制。四五行、三行或固定像素都不是生产阈值；器件库尺寸变化会自然改变设施成本。副本数量不按图规模或固定上限截断，避免用“最多两个”把第三个远距簇重新拖回长干线，也避免紧凑工整消费带退化为每边一个同名图案。

每个副本保留同一 logical name，由消费者连续分区分配。只有候选不增加节点重叠、器件/文字穿线、方向错误、异网重合、交叉和折点，并且减少交叉或扣除副本成本后减少线路长度时才采用。面积只在前述指标完全相同时作为次级比较，不能否决更短、更少交叉的清晰路线。中间节点和末端禁止复制，逻辑图节点数保持不变。

所有水平/垂直判定使用统一数值容差。端口坐标经不同乘加路径得到的微小浮点尾差不能把直线归入斜线碰撞分支；用两端轴坐标均值执行相交测试，超过容差的真实斜线仍拒绝。该容差只稳定计算，不移动最终图。
