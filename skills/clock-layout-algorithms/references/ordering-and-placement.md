# 行序与坐标

## 交叉最小化

对相邻层进行上下往返 sweep，用邻居重心/中位数产生候选顺序，并用稳定实例顺序打破平局。对高复用源、汇聚 mux 和长边，要把虚拟边段纳入计数，不能只看相邻真实节点。

候选比较至少统计真实端口连线的交叉，而不是节点中心线交叉。末端一分二与相邻单线支路、双源交错汇聚、长短不对称 mux 输入是必测反例。

## 对齐结构相似的支路

相似支路可能少一个或多一个器件。按 rank/`layout_column` 确定语义列后，在行序阶段让共享前驱、共享后继和相同列偏好的节点保持邻近。不要因链长不同让整列 mux 左右摇摆。

## 坐标分配

在固定层序后分配 y 坐标：

- 节点矩形和标签矩形不重叠；
- 同一条简单水平链优先让相邻端口共线；
- 紧凑化只能减少真实空白，不能侵入 visible footprint 或路由净空；
- 对齐比面积优先，避免本可直连的边出现一次上下折返。

可采用 Brandes–Köpf 类垂直对齐/水平紧凑思想，但要覆盖其已知勘误，并以项目几何门禁验证结果。

## 零入度显示设施与消费者走廊

逻辑根可有多个等价显示设施。列选择以每个物理设施实际服务的边为单位：单边设施应搜索目标左侧
的连续最右可行坐标；若器件/标签宽度使现有间隙不足，可把目标列及其右侧后缀作为一个刚体平移，
同时重接所有受影响端点。多边设施的一条远端边可在同一个事务中拆成新设施；只验收完整事务，
不把暂时未接线的中间状态暴露给门禁。候选必须严格改善交叉、折点或线长的质量向量，并保持同源
网络无 split–rejoin、无空或可无损合并的冗余设施。该规则仅依赖零入度、边归属、可视框和端口，
不得识别 `source`、`from`、`xtal`、实例名或样例编号。

已形成的视觉源列是软对齐基准：在端口、碰撞、异网重叠、交叉和折点相同的情况下，保持该列，
不能只为缩短一条已经笔直且无交叉的线把根打散。只有确实减少交叉或折点时，消费者附近的中间列
才支配整齐列。视觉列按最终输出端口横坐标聚类，聚类尺度来自根设施可视宽度；同列器件不同端口
偏移不能被误算成多个列。

根设施迁移和消费者后缀走廊是耦合坐标 owner。任一走廊移动后，必须使其增量 assessment 失效，
用完整当前几何重新建立下一次设施迁移基线；二者交替到整轮均无接受项。否则走廊新打开的直线路径
会被旧缓存漏掉。连续二维搜索只在拓扑工作预算允许的精确层运行；可扩展层仍要求严格向右的规范
列候选，不能因“已有航点”把当前列纵移混入大图全图反事实。

扩开消费者后缀还必须保持独立 DAG-ALAP 层序包络：任一无显式列约束、仅一条出边且最新可行层
大于零的根，其可视中心必须位于前一 ALAP 层全部主节点的右侧。该 rank 由只含拓扑边的独立正向
earliest/反向 latest 遍历重算，不能复用带源提升、cohort 或其它被测策略的生产 rank。仅检查每条
边仍向右不足以发现“前一层被扩到后一层根右边”的全局列序反转。

## 末端行与频率列

用零出度判定末端，不按 `clock` 器件名写分支。末端全部放在最右 rank，每个末端独占一个不重复行轴。右侧频率注释按真实入口轴对齐，列宽由标题和所有值的可见宽度决定，并纳入 SVG 边界。
