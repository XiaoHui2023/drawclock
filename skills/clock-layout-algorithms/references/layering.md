# 图模型与分层

## 规范化图

每条逻辑边必须包含：源实例、源端口、目标实例、目标端口。引用、端口和 DAG 验证通过后才能布局。器件类型只提供尺寸、标签范围和端口，不决定层级规则。

## 从左到右分层

基础 rank 由最长路径或网络单纯形思想计算，使每条边满足 `rank(source) < rank(target)`。跨多层边可以在内部使用虚拟节点参与排序，但不得输出成用户器件。

零入度节点是源头，零出度节点是末端；不要把 `from`、`source`、`clock` 等名称写入算法判断。源头不必固定在最左列：如果它只服务中后部，可以右移到最早消费者之前，以缩短线路和减少交叉。

## `layout_column`

`layout_column` 是可选整数偏好：较小值偏左，较大值偏右，相同值尽可能同列。数字只表达相对顺序，不保留空列。

处理顺序：

1. 将同值节点收缩成约束组；
2. 把连接方向与组间顺序合成偏序；
3. 按连接方向排序并展开成连续 rank；
4. 若偏好与有向边冲突，以左到右连线正确性为硬约束并报告/稳定降级。

这是用户对列的权重，不是绝对坐标；不得因满足列偏好引入反向边。
