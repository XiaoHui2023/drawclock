## 期望结果

- 零入度逻辑根的消费者形成远距、分离消费带，且单设施长主干会造成更长走线或更多交叉时，按完整几何收益使用多个同名显示设施；逻辑节点和逻辑边保持唯一。
- 公共根跨越多行时，主干保持在整体外侧或可见空闲边界，禁止在中部过早进入两行之间再向下贯穿其它网络；只有完整反事实证明内部通道更优时才允许进入。
- 新增要求或指标不得删除、覆盖或缩小既有要求。冲突必须形成显式冲突记录并阻断发布。
- 每张公开 SVG 都执行质量注册表的完整指标 exact-set；每个指标均有适用性回执、正例、边界例和 mutant。
