## 期望结果

- 每条用户反馈在产品修复前均由冻结旧版本、公开 CLI、有效 JSON 和只读 Oracle 自然复现两次。
- 人工改图、故障注入、变异测试和自报状态不能解锁产品 owner。
- 未复现、入口未到达、证据缺失、问题仍开放或声明范围扩大时，机器门非零退出。
- commit、push、release 与完成声明消费当前 issue 集合和制品身份；不能复用旧 PASS。
