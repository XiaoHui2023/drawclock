# 多器件库输入与合并

## 状态

- status: active
- owner: agent
- updated: 2026-08-25

## 期望结果

- `-l/--library` 可在一次命令中接收多个文件和目录，也可重复传参。
- 目录递归扫描 `.xml`，路径去重并按稳定顺序合并。
- 单文件器件库与多器件器件库使用同一解析规则。
- 重复器件 title、空目录、非 XML 文件和不存在路径均给出明确错误，不静默覆盖。
- 单文件旧用法保持兼容。

## 当前证据

- failure: 当前 CLI 的 `--library` 只接受一个文件，内部缓存和端口解析也以单个路径为键。
