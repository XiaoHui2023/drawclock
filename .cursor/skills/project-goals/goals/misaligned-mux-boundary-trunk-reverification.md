## 期望结果

- 冻结旧版通过公开 CLI 自然生成公共总线提前横穿、随后纵向贯穿分支区的失败图，并证明目标 MUX 相对同组普通 MUX 更靠右。
- 当前版对同一输入优先沿公共纵向主干到整体边界附近，再横向接近错列目标；不得只降低总交叉数而保留目标症状。
- 每个当前 SVG 执行统一质量注册表的完整指标集合；过早内部入口指标必须有适用性证明、失败 witness、成功基线与故障注入。

- 由通用检查器提取同一输入旧版与当前版每根线的点列、方向、位置、长度、拐点、交叉、重叠、分叉、汇合和主干结构，并由 Agent 独立判定修复结果；用户不承担质量检查工作。
- 攻击停止条件改为覆盖驱动：目标横向错列、目标纵向区段、公共分支密度、上下游链深、端口、额外消费者、声明顺序、障碍带、约束和后置 owner 的取值覆盖、全部高风险二元交互及已知三元交互必须 exact-set 闭合；case 数或固定轮数不能授权完成。
