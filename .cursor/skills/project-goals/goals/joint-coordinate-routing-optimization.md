# 坐标与正交路由联合优化

## 状态

- status: complete
- owner: agent
- updated: 2026-08-14

## 期望结果

- 分层坐标与正交路线使用同一个全局质量目标迭代，任何器件类型、名字、规模或固定结构都不触发专用分支。
- 仅接受严格减少可避免拐点且不增加端口误差、节点或文字穿线、不同网络重叠、交叉、主干碎裂、节点重叠和画布裁切的候选；面积是次要指标。
- 独立判定器从最终坐标枚举可行的结构性改进，不调用生产优化器的候选生成或评分代码。
- 入度为 0 的逻辑节点在消费域相距很远时可以有多个显示锚点；中间节点和终端始终只有一个。显示锚点不得改变输入配置、逻辑节点数、端口或边的归属。
- 已知失败、已知成功、主动注入错误、随机连接关系、器件库几何变化及 512/1024/2048/4096 压力图均有机器证据。
