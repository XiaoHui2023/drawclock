# 非对称汇聚异常外凸与根主干碎裂

## 状态

- status: done
- owner: agent
- updated: 2026-08-14

## 期望结果

- 非对称汇聚结构中的局部输入边不存在可避免的反向外凸、额外折返或由此引入的兄弟边交叉。
- 两个或多个根的分发主干不得形成无拓扑依据的 `A / B / A` 纵线次序；同一源端口只有在目标轴存在可证明的大间隔时才允许多个局部主干。
- 机器门禁从最终坐标独立证明同层父端口顺序是否反转，并独立比较更简单路线是否支配当前路线，不依赖生产路由器内部候选。
- 最小反例、拓扑变体、随机性质语料和既有压力图同时通过。

## 当前证据

- failure: 用户观察到 `from a -> gate a -> div a -> sel` 与 `from b -> gate b -> sel` 中，`gate b -> sel` 无故外凸并与 `div a -> sel` 交叉；现有门禁未拒绝该结果。
- failure: 两个 `from` 的分发出现三根纵线，次序为 `from A / from B / from A`；A 被无故拆成两根总线，现有局部主干判定未拒绝。
- success: 两种长短分支镜像最小反例均通过，汇聚兄弟输入零局部可避免交叉、零可避免外凸。
- success: A/B/A 主干由 `fragmented_fanout_sources` 硬门禁覆盖；多根聚类语料为零碎裂。
- success: 两折局部交叉和四折支配路线故障注入均被拒绝；12-seed 性质语料 12/12 通过（1.22 秒）。
- success: 全仓 389 passed / 1 conditional skip；解压 Windows 包完整 frozen smoke 通过；GitHub Release run 31763272438 全绿，远端 Linux 包在隔离 PATH 的 Docker 中执行编号 20 并通过 SVG 几何 oracle。
