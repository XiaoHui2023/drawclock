# 设计笔记

## 产品范围

- drawclock 只把时钟连接配置和指定的 draw.io 器件库转换为 SVG。
- 唯一入口是 `python src` 或安装后的 `drawclock`。绘图是主功能，无子命令。
- 必填参数为 `-i/--input`、`-l/--library`、`-o/--output`；`--crossing-style` 保留 `arc`、`gap`、`sharp`、`none`，默认 `arc`。
- 输出内容始终是 SVG，文件后缀不改变格式。
- 配置由 configlib 读取，支持 JSON、JSONC、JSON5、TOML、YAML、YML、INI、CONF 和 CONFIG。
- v0.0.0 tag 与 Release 保存旧的 extract/reload 版本；v1.0.0 起源码、CLI、示例、测试和发行包只含绘图功能。

## 配置与器件库

- 顶层字典键是实例名。每个器件只要求 `kind`；根器件可以省略 `source`。
- `kind` 直接对应 `--library` 中的器件 title，不按名字、连接端口或内置器件表猜测。
- 多输入器件的 `source` 使用稀疏字典，未列出的有效输入端口可以不连接。
- 多输出引用写成 `器件名[输出键]`。
- `component`、`*_kind`、`freq`、`ratio` 等不是通用必填字段；附加属性由当前器件库定义。
- `layout_column` 是可选整数等级。较小值靠左，较大值靠右，相同值尽可能共列。数值只表示顺序，不保留数值间的空列；省略时只按连接关系布局。
- `from` 与 `source` 都按普通零入度器件处理，不含导出或跨图特殊语义。

## 布局与布线

- 图从左到右分层；器件位置、端口、标签范围和路线全部由当前配置与器件库计算。
- 禁止按实例名、器件类型、示例文件或节点数量写专用分支。
- 优先级依次为端口正确、无器件或文字穿越、无节点重叠、不同网络不重合、减少交叉、减少拐点、路线整齐；长度和画布面积排在这些指标之后。
- 同一输出端口连接多路下游时，共用一条纵向分发主干，各目标保留独立横向支线。
- 零入度器件的消费簇相距很远且服务代价更低时，可以创建保持逻辑身份不变的显示副本；中间与末端器件不能复制。
- 非对称分支中，若一个中间器件同时连接继续向后的支路和跨越中间列的末端，布局器按入度、出度和列跨度找出独占上游链。整组移动后只在硬几何指标不变差且总拐点严格减少时接受。
- 整组换行候选只用于结构质量模式；高复用域模式不执行全局候选扫描。模式由连接集中度和跨层工作量决定，不以节点数设分界。
- 单点联合优化处理四个以上拐点的异常；正常 H-V-H 线不进入全局枚举。
- 两拐点边还要检查坐标可移动性：若源节点属于从零入度节点开始、每个节点只有一个下游的完整独占链，整链移动到目标端口轴后只在具体重叠对象、穿线对象、异网重合、交叉和公共主干均不增加且总拐点减少时接受。硬错误按对象对比较，不只比较总数。
- 同等级节点收缩为约束节点，相邻等级增加一条次序边，一次最长路径扫描计算最早可行列，复杂度为 `O(V + E + L)`。相同等级存在因果依赖或较大等级必须位于较小等级上游时，连接方向优先，不强制满足等级。

## 质量检查

- Agent 检查端口坐标零偏差、水平引出、每条逻辑边恰好一次、正交线段、器件与文字穿越、节点重叠、异网重合、交叉、锯齿、可避免拐点、源主干碎裂、显示副本合法性和 SVG 边界。
- 可避免拐点分为固定节点路线候选、单节点联合候选和独占根链整组候选；每类都有独立故障注入。
- 故障注入覆盖错误端口、缺边、重复边、斜线、文字穿越、终端排序交叉、汇聚外凸、源主干重复和显示副本身份错误。
- 性质语料改变器件名字、类型、尺寸、端口、链深、根复用和连接顺序。
- 列等级检查包括不同前后深度、无提示基线、输入逆序、远距整数、不同器件、因果冲突、整列位移和等级逆序；Agent schema 11 分开报告同等级错位与相邻等级逆序。
- 压力配置覆盖 512、1024、2048 和 4096 个末端时钟。4096 生成预算为 30 秒；美观与几何正确不为更小画布让步。
- 质量检查只存在于测试与 Agent 记录，不是公开 CLI 功能。

## 发布

- PyInstaller 可执行文件随包带 Node.js 与 ELK 运行时，不依赖宿主 PATH。
- 发行包包含主程序、runtime、`drawio-lib/`、`example/draw.json`、README、`draw.md` 和源码参考。
- 发布前从真实 ZIP 解压，在隔离 PATH 下测试直接入口、任意输出后缀、所有配置格式、默认圆弧、示例、复杂图和 512 时钟压力图。
- 每次修改通过检查后读取用户根 `github-upload` 与 `github-release` 规则，提交、推送并发布当前 `pyproject.toml` 版本。
