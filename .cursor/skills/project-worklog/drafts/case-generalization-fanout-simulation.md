# 举一反三：扇出数组模拟总结草稿

## 精确基线

- 016：唯一公共 `from` 分别进入六个逐路公共 gate；私人侧逐路多一层 div，再在 mux 汇聚。
- 017：四个 source 直接进入同一 mux，辅助链只用于自然形成不同列；source_2 同时服务第二消费者。

## 相邻矩阵

| 维度 | 已有/待补用例 | 期望 |
| --- | --- | --- |
| 分支深度 | 等深、私人深一层、声明顺序翻转 | 规则公共根均保持单设施总线 |
| 列 | 显式错列干净反例、自然错列多目标 | 错列本身不报错；存在支配候选才失败 |
| 数组规模 | 3、4、6、8 路 | 不依赖固定六路或固定行预算 |
| 结构规则性 | 同构阵列、远距非规则域 | 前者保总线；后者仍可按全局成本拆分 |
| 顺序 | 节点声明与端口顺序置换 | 结构指标不变 |
| 根域 | 一个公共根、两个独立公共域 | 每个网络独立追踪，不错误合并 |

首轮已实现 pairwise 子集：`(3, 等深, 正序)`、`(4, 深一层, 逆序)`、`(6, 等深, 逆序)`、`(8, 深一层, 正序)`，以及四源 mux 的端口原序/置换；显式错列零折点继续作为干净反例，远距非规则域由既有 source-replica boundary 保持。

## 当前根因与指标候选

1. 三个设施创建 owner 中，任一未消费规则阵列不变量都会重新产生副本；指标需枚举最终物理设施，而不是只断言某阶段报告。
2. 偶数消费者中点与端口轴可能 L1 同优；质量向量需在长度不增前提下以更少折点破平局。
3. 错列、异深和扇出只是特性，只有独立反事实严格支配才是缺陷；每个红灯必须配一个同前提绿边界。

项目指标已登记到布局能力合同与覆盖账本；success/fault/boundary 三角色分别绑定当前公开 CLI、冻结双跑收据和相邻干净反例。双公共根域隔离边界要求每个逻辑网络分别一设施一纵线且异网重叠为零；两条不相交的纵线允许复用同一 x，不把坐标不同误当语义隔离。全量 467/467 通过，Windows 新鲜包与远端 Linux 回下载消费均确认 29/30 在包内、512+ 输入为 0；本草稿作为已验证模拟总结收敛。

复发后的扩展结论：复杂基线覆盖公共根额外消费者、混合 gate/cell、私人链深变化、mux 后级变化以及四源三列辅助扇出。五轮递归攻击第一次在 R5 seed 018 找到后置 owner 重新制造的 017，修复后才取得连续 5 轮；全量又捕获交叉共享根误分类，并增加“逐路私有对侧根”边界。当前最终结果为 471 passed、5 skipped，Windows 包 25 个示例且无 512+；待远端发行成功后将草稿状态改为 done。
