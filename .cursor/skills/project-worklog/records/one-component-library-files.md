# 单文件单器件库迁移

- status: done
- created: 2026-08-26 09:42 +08:00
- updated: 2026-08-26 10:21 +08:00
- scene: 器件库从单文件全集迁移为一文件一器件

## 当前事实

- 公开 CLI 已支持一次提供多个路径、重复 `-l`、目录递归扫描、稳定排序与路径去重。
- 内置库仍由 `drawio-lib/drawclock.xml` 单文件承载全部器件；加载器也允许单文件多条目。
- 发行 manifest、冻结 smoke、源码 smoke、示例脚本和文档仍绑定旧文件路径。

## 已实施

- 内置库目标改为 `drawio-lib/drawclock/` 目录，生成器按 title 写入独立 XML。
- 每个文件保持标准 draw.io `<mxlibrary>` 格式，数组内恰好一个条目，不增加 drawclock 私有包装。
- 运行时加载器与构建校验器开始强制“一文件恰好一个器件”，并对缺字段和无顶点样式失败关闭。
- 布局示例脚本、布局/端口/压力测试和冻结消费脚本的默认库入口已切换为目录。
- 多库测试夹具不再拆出多条目文件；自定义器件测试改为复制目录后只替换一个器件，并新增旧式多条目文件拒绝反例。
- 冻结包混合输入门改为“一个独立文件 + 一个其余器件目录”；源码 manifest 和源码 smoke 已按器件目录逐文件校验。
- 发行包结构测试已要求组件 XML 位于 `drawio-lib/drawclock/`，并明确拒绝旧的 `drawclock.xml` 路径。
- CLI、源码部署、示例、器件库说明、项目 Skill、设计笔记和 changelog 已统一到单文件单器件合同。
- 旧的 `drawio-lib/drawclock.xml` 全集已移除，下一步由生成器创建组件目录产物。
- 生成器在 0.449 秒内写出 23 个单器件 XML；全部 draw.io 结构、器件几何和端口校验通过。
- 首轮聚焦回归 51 项通过，用时 10.382 秒。
