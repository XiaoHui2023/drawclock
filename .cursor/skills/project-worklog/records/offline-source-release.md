- 用户明确要求 `src/` 作为 Linux 归档内独立入口；现有 Shell 示例与其它归档内容保持冻结程序入口。
- 已修改组包器，使 Linux 归档动态复制产品 `src/*.py`，Windows ZIP 的 exact-set 保持原样；归档检查器现校验 Linux 源码集合和逐文件字节，并拒绝缓存或额外源码。
